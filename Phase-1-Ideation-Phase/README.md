# Phase 1 – Ideation Phase

## Project Name
**Incident Lifecycle Automation in ServiceNow**

## Overview
This phase focuses on identifying the problem, understanding user needs, brainstorming ideas, and selecting the project concept.

## Problem Identified
Incidents may be reported through email, phone, or informal communication, leading to inconsistent incident recording, unclear ownership, delayed escalation, limited SLA visibility, and difficulty tracking related records.

## Selected Solution
**Incident Lifecycle Automation in ServiceNow**

The project aims to standardize and automate the Incident Management lifecycle in ServiceNow.

## Documents

- **Brainstorming_Idea_Generation_and_Prioritization.docx** – Brainstorming, idea grouping, and prioritization.
- **Define_Problem_Statement.docx** – Customer problem statements for End Users and Service Desk Agents.
- **Empathy_Map.docx** – End User empathy map, expectations, pain points, challenges, and gains.

## Phase Outcome
The Ideation Phase establishes the project problem, user needs, possible solutions, and the selected project concept.
