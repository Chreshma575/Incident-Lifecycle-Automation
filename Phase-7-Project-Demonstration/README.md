# Phase 7 – Project Demonstration

## Project Name
**Incident Lifecycle Automation in ServiceNow**

## Overview
This phase contains the demonstration video of the completed Incident Lifecycle Automation in ServiceNow project.

## Demo Video

- **Project_Demo.mp4** – Demonstrates the key features and workflow of the ServiceNow Incident Management lifecycle.

## Demonstration Coverage

The project demonstration covers:

- Incident Creation
- Incident Classification
- Knowledge and Agent Assist
- Assignment and Reassignment
- Level 2 Incident Investigation
- Emergency Change Request
- Child Incident Creation
- Incident Resolution
- Knowledge Article Creation
- SLA and Related Record Validation

## Phase Outcome

The Project Demonstration Phase provides a practical demonstration of the implemented **Incident Lifecycle Automation in ServiceNow** workflow and its major features.
